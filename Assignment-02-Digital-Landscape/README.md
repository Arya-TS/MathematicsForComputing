## Mathematical Functions Used

- Linear equations – ground, house walls, and tree trunk
- Circle equations – sun and tree canopy
- Absolute value functions – mountains and house roof
- Trigonometric function – river
- Domain restrictions – used to limit equations to the required portions

## Explanation

I created a digital landscape using different mathematical functions in Desmos. Linear equations were used to construct the ground, walls of the house, tree trunk and other straight edges. Circle equations were used for the sun and tree canopy. Absolute value functions were used to create the mountains and roof of the house because they form pointed shapes. A trigonometric sine function was used to represent the river with a wave-like pattern. Domain restrictions were applied to limit the graphs so that each equation represented only the required part of the landscape. This demonstrated how different mathematical functions can be combined to create a meaningful graphical design.
