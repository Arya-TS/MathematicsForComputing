# Statistical Analysis of Examination Marks

This project performs descriptive statistical analysis on the examination
marks of 30 students using Python/PyStats.

## Analysis Performed

- Number of observations
- Minimum, maximum and range
- Mean, median and mode
- Quartiles and IQR
- Variance and standard deviation
- Coefficient of variation
- Percentiles
- Skewness
- Kurtosis
- Five-number summary
- Outlier detection using the 1.5 × IQR rule
- Histogram
- Horizontal box plot

## Tools Used

- Python
- PyStats
- NumPy
- SciPy
- Matplotlib
- Google Colab
