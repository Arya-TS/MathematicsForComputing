# Assignment 08 – Eigenvector Basis and Linear Transformation

This assignment demonstrates a 3D linear transformation using a transformation matrix and represents the given points in both the standard basis and the eigenvector basis.

## Contents

* `main.py` – Python program for calculating eigenvalues, eigenvectors, transformed points, and visualizing the transformation.
* `input.txt` – Input 3D points used by the program.
* `output.png` – Screenshot of the program output and visualization.

## Concepts Used

* Linear transformations
* Eigenvalues and eigenvectors
* Eigenvector basis
* Basis transformation
* Matrix multiplication
* Diagonalizability
* 3D visualization using Matplotlib

## Requirements

```text
Python
NumPy
Matplotlib
```

## Execution

Run the program using:

```bash
python main.py
```

The transformation matrix is entered through the terminal, while the 3D points are read from `input.txt`.
