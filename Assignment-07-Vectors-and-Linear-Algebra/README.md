# Vectors and Linear Algebra

A LaTeX Beamer presentation on **Vectors and Linear Algebra** prepared for the **Maths for Computing** course in the **M.Tech Artificial Intelligence & Software Engineering** programme at **Cochin University of Science and Technology (CUSAT)**.

## Contents

The presentation covers:

### Vectors and Vector Operations

* Vectors
* Coordinate System
* Vector Addition
* Scalar Multiplication
* Linear Combinations
* Span
* Basis
* Linear Independence and Dependence

### Matrices and Linear Transformations

* Matrix Multiplication
* Composition of Linear Transformations
* Three-Dimensional Linear Transformations
* Nonsquare Matrices as Transformations Between Dimensions

### Systems of Linear Equations

* Systems of Linear Equations
* Consistency of Solutions
* Matrix Form $A\mathbf{x}=\mathbf{b}$
* Inverse Matrix Method
* Gaussian Elimination
* Cramer's Rule

### Matrix Spaces

* Determinant
* Inverse Matrices
* Column Space
* Null Space
* Rank

### Vector Geometry

* Dot Product
* Duality
* Cross Product
* Cross Product and Linear Transformations

### Change of Basis and Eigenvalues

* Change of Basis
* Coordinate Transformations
* Eigenvalues
* Eigenvectors
* Eigenspaces
* Diagonalization

### Applications

* Machine Learning
* Principal Component Analysis
* Neural Networks
* Computer Graphics
* Image Representation
* Embeddings
* Graphs and Networks
* Numerical Computing
