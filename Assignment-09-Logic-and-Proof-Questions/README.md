# Logic and Proof

A LaTeX Beamer presentation containing **application-based questions and solutions on Logic and Proof** prepared for the **Maths for Computing** course in the **M.Tech Artificial Intelligence & Software Engineering** programme at **Cochin University of Science and Technology (CUSAT)**.

## Contents

The presentation contains five application-based questions for each of the following topics:

### Logic Foundations

* Introduction
* Proofs
* Propositions
* Predicates and Quantifiers
* Truth Tables
* First Order Logic
* Satisfiability

### Proof Techniques

* Pattern of Proof
* Proofs by Cases
* Proof of an Implication
* Proof by Contradiction
* Proving IFF

### Set Theory

* Sets
* Proving Set Equations
* Russell's Paradox
* Well-Ordering Principle

### Inductive Proof Techniques

* Mathematical Induction
* Invariants
* Strong Induction
* Structural Induction
